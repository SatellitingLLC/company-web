# 🛰️ satelliting.space

The website for [Satelliting LLC](https://satelliting.space), a remote-first web studio. We build fast websites so your business can be found, and this is the one we built for ourselves. (Yes, the cobbler's kids finally got shoes.)

Built with Next.js, React, Tailwind, and TypeScript.

## Launch sequence

```bash
pnpm install
pnpm dev      # liftoff at http://localhost:3000
```

Other buttons: `pnpm build`, `pnpm start`, `pnpm lint`.

## Where stuff lives

- `app/` - pages and routes (home, about, projects, contact)
- `components/` - the bits the pages are made of
- `content/` - the words. Edit copy here, not in components
- `public/` - images and the logo
