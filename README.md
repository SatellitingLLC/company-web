# Satelliting LLC

A modern, space-themed Software Engineer's portfolio.

## Tech Stack

- **Framework**: [Astro](https://astro.build/) v4
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) v3
- **Content**: Astro Content Collections
- **Contact Form**: [Web3Forms](https://web3forms.com/)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
src/
├── components/     # Reusable Astro components
├── content/        # Content collections (projects)
├── layouts/        # Page layouts
├── pages/          # Route pages
└── styles/         # Global styles
public/
├── images/         # Static images
└── logo.png        # Site logo
```

## Features

- **Space-themed Design**: Dark mode with cyan/green aurora gradients and animated stars
- **Content Collections**: Projects managed as markdown files with frontmatter
- **Contact Form**: Web3Forms integration for serverless form handling
- **Responsive**: Mobile-first design with smooth animations
- **Performance**: Static site generation for fast loading
